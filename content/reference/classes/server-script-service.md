## Summary

`ServerScriptService` is a container for most [Scripts](https://create.playvortex.io/reference/classes/script/) (since they can also be placed in [Workspace](https://create.playvortex.io/reference/classes/workspace/)). Similar to [StarterPlayerScripts](https://create.playvortex.io/reference/classes/starter-player-scripts/), which contains [LocalScripts](https://create.playvortex.io/reference/classes/localscript/).
